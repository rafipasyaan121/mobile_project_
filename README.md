# kartu_profil_digital

Aplikasi Flutter kartu profil digital.

## Menjalankan aplikasi

Pastikan terminal berada di folder yang berisi `pubspec.yaml`. Jika terminal
dibuka dari folder induk `PROJECT_MOBILEfakhry`, masuk ke folder proyek terlebih
dahulu:

```powershell
cd .\kartu_profil_digital
```

Lalu jalankan:

```powershell
flutter pub get
flutter devices
flutter run
```

Jika ingin memilih target secara spesifik, gunakan salah satu perintah berikut:

```powershell
flutter run -d windows
flutter run -d chrome
```

Untuk Android, nyalakan emulator atau sambungkan perangkat, lalu pilih ID
perangkat yang ditampilkan oleh `flutter devices`.

Jangan jalankan perintah Flutter dari folder induk; file `pubspec.yaml` aplikasi
berada di folder `kartu_profil_digital`.
